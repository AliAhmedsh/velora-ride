# Velora Ride

Premium customer app for the Velora mobility platform.

## Design

- **Font:** Urbanist
- **Theme:** Warm brown palette with cream backgrounds
- **Stack:** React Native CLI · TypeScript · React Navigation · Redux Toolkit · React Query

## Setup

```bash
npm install
npx react-native-asset
npm run android   # or npm run ios
```

## Screens

- Welcome & OTP authentication
- Home with Local Ride, City to City, Rental
- Wallet, Trip history, Profile
